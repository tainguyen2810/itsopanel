# G5: Nâng cấp 3 phiên bản + rollback giữa chừng

- **Trạng thái:** `pending_vm` — chưa chạy trên VM (2026-11-23, `v1.0.0-rc.1`). `v1.0.0` chỉ khi G1–G8 đều `pass` (D-15, D-47, ADR 0060).
- **Tiêu chí (ROADMAP §Production Gate):** Nâng cấp qua 3 phiên bản liên tiếp, rollback giữa chừng, site không gián đoạn.

## Tiêu chí đo được

1. A → B → C → rollback (về B) → C; `itso doctor` sạch
2. Site account 0 lỗi HTTP suốt quá trình (5 yêu cầu/giây)
3. 20 vòng update/rollback + kill -9 ở 6 bước journal + mất điện (`tests/vm/upgrade-loop.sh`)

## Đã kiểm tự động trong container (CI)

- Go `TestUpdateCrashAtEachStep`, `TestRepairRollsBackWhenFinishUnhealthy`, `TestUpdateHistoryAndOrder`, `TestUpdateRollbackAndPrune`
- `make test-installer` 20/20 (chữ ký, sha, offline bundle)

Lệnh và kết quả thật: `TEST_REPORT.md` (Phase 12), báo cáo `docs/reports/phase-12.md`.

## Phần VM

`sudo bash tests/vm/upgrade-loop.sh --release A --release2 B` (tạo site vm12) rồi `sudo bash tests/vm/gate.sh --release A --release2 B --release3 C --only G5`.

Cần 3 bản release thật liên tiếp (ví dụ 1.0.0-rc.1, rc.2, rc.3).

Sau khi chạy: dán bảng của `/root/itso-vm-gate.md` vào mục **Bằng chứng** dưới đây, ghi ngày/phiên bản/cấu hình VM, rồi
`--record` (hoặc `php artisan itso:gate-record G5 <pass|fail|partial>`) để trang **Sẵn sàng production** hiển thị.
