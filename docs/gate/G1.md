# G1: Cách ly account (≥ 2 server)

- **Trạng thái:** `pending_vm` — chưa chạy trên VM (2026-11-23, `v1.0.0-rc.1`). `v1.0.0` chỉ khi G1–G8 đều `pass` (D-15, D-47, ADR 0060).
- **Tiêu chí (ROADMAP §Production Gate):** Account A không đọc, ghi hay liệt kê được file, tiến trình, DB, socket, backup của B, qua PHP, cron, SFTP, Terminal, File Manager. 100 % pass trên ≥ 2 server.

## Tiêu chí đo được

1. `ls /home/<B>` từ UID A → Permission denied (E5)
2. PHP/cat của A đọc file của B → thất bại (E6)
3. `ps aux` của A chỉ thấy tiến trình của A (E7, `hidepid=invisible`)
4. `sudo -l -U itso` rỗng (E8)
5. Cùng 4 mục trên server thứ hai (node Phase 9)

## Đã kiểm tự động trong container (CI)

- Pest `tests/Feature/Phase12/RouteMatrixTest.php`: > 250 route có `{id}` gọi bằng ADMIN ngoài phạm vi / USER khác → chỉ 403/404 (12.4)
- Go `internal/fsx` (`TestTraversalAndAbsoluteRejected`, `TestSymlinkOutsideBlocked`), `TestBackupRestoreSymlinkAtTarget`: đường dẫn account không thoát ra ngoài home
- Go `TestPeerNotAllowed`, `TestPeerCred`: chỉ UID được phép gọi agent socket
- Pest Phase 6 (File Manager, SFTP, Terminal, Cron) kiểm phạm vi account ở tầng panel

Lệnh và kết quả thật: `TEST_REPORT.md` (Phase 12), báo cáo `docs/reports/phase-12.md`.

## Phần VM

`sudo bash tests/vm/gate.sh --release A --only G1 --node-report <báo cáo enforcement.sh chạy trên node>`; trên node: `sudo bash tests/vm/enforcement.sh` (sau khi join theo `tests/vm/phase9.sh`).

Thiếu báo cáo server thứ hai → `partial`.

Sau khi chạy: dán bảng của `/root/itso-vm-gate.md` vào mục **Bằng chứng** dưới đây, ghi ngày/phiên bản/cấu hình VM, rồi
`--record` (hoặc `php artisan itso:gate-record G1 <pass|fail|partial>`) để trang **Sẵn sàng production** hiển thị.
