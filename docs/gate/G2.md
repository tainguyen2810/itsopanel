# G2: Quota

- **Trạng thái:** `pending_vm` — chưa chạy trên VM (2026-11-23, `v1.0.0-rc.1`). `v1.0.0` chỉ khi G1–G8 đều `pass` (D-15, D-47, ADR 0060).
- **Tiêu chí (ROADMAP §Production Gate):** CPU/RAM/process/IO/disk/inode bị chặn đúng giới hạn, không ảnh hưởng account khác.

## Tiêu chí đo được

1. `stress-ng --cpu 8` với CPU 100 % → throttled, ≤ ~1 core (E1)
2. Cấp phát 600 MB với MemoryMax 256 MB → OOM trong slice, agent + account khác sống (E2)
3. Fork bomb dừng ở TasksMax (E3)
4. `dd` vượt disk hard → EDQUOT (E4, cần quota kernel `usrjquota`)

## Đã kiểm tự động trong container (CI)

- Go `TestQuotaGolden`, `TestAccountEnsureGolden`: tham số slice/quota sinh đúng
- Pest quota/usage (Phase 4, 11): giới hạn gói, vượt hạn mức bị từ chối ở panel

Lệnh và kết quả thật: `TEST_REPORT.md` (Phase 12), báo cáo `docs/reports/phase-12.md`.

## Phần VM

`sudo bash tests/vm/gate.sh --release A --only G2`.

E4 chỉ đo (không quota kernel) → `partial`.

Sau khi chạy: dán bảng của `/root/itso-vm-gate.md` vào mục **Bằng chứng** dưới đây, ghi ngày/phiên bản/cấu hình VM, rồi
`--record` (hoặc `php artisan itso:gate-record G2 <pass|fail|partial>`) để trang **Sẵn sàng production** hiển thị.
